# 2.0 体验优化路线图

> 产品录入端跑通后的下一阶段：以体验与可用性为主的优化。

## 当前基线（1.x）

- 产品管理：仅列表、无主图、链接优先；新增/编辑/详情流程可用
- 仪表盘：分类/渠道/品牌筛选、排行榜、图表、产品详情浮层
- 布局：侧栏导航、多语言、用户菜单、同步状态
- 登录：邮箱/密码、忘记密码、错误提示

## 本轮已实施

- **仪表盘**：价格与销量看板统一以**优惠后价格**（到手价/券后 `actualPrice`）为基准；新增**品牌性价比定位**坐标图（同品类同平台，X=价格指数、Y=销量，按品牌聚合）。
- **全局 Toast**：保存成功、编辑保存成功、删除成功、同步完成时底部轻提示，3 秒自动消失。
- **产品列表空状态**：无数据时展示图标 + 文案「添加第一个产品或调整筛选条件」+ 可编辑权限下「添加产品」按钮。

## 2.0 优化方向（可拆分迭代）

### 导航与布局

- [ ] 侧栏：移动端展开/收起动效与触控体验
- [ ] 当前页高亮与面包屑（可选）
- [ ] 全局「最后保存」时间展示是否足够明显、是否需要「一键同步」入口强化

### 产品列表（ProductInventory）

- [x] 空状态：无产品时的引导（插图 + 文案 + 快速「添加产品」）
- [ ] 加载态：首屏/筛选后骨架屏或列表 loading，避免空白闪屏
- [ ] 列表：行高、行距、链接可点击区域是否舒适；列宽在小屏下的表现
- [ ] 搜索/筛选：占位符、清空按钮、筛选结果数量提示
- [ ] 分页或「加载更多」：数据多时的体验统一

### 产品详情与编辑

- [ ] 详情浮层：打开/关闭动效、键盘 Esc 关闭、焦点陷阱
- [ ] 编辑弹窗：必填项校验、保存中禁用按钮与 loading、成功/失败 toasts
- [ ] 表单：长表单分组或分步、关键字段的说明或 placeholder 优化

### 仪表盘（Dashboard）

- [x] 品牌性价比定位坐标图（同品类同平台 · 价格指数 vs 销量）；价格/销量看板以优惠后价格为基准
- [ ] 空状态：无数据时的说明与引导
- [ ] 图表：无数据时的占位与说明；图例与坐标轴可读性
- [ ] 排行榜卡片：点击反馈、加载更多/展开的交互统一

### 登录与鉴权

- [ ] 登录页：错误信息展示位置与样式统一；加载中状态
- [ ] 会话过期：统一提示与跳转登录的体验

### 反馈与一致性

- [x] 全局 Toast/轻提示：成功保存、删除、同步完成、网络错误等
- [ ] 按钮：主要/次要/危险样式统一；loading 态统一
- [ ] 表格与卡片：边框、圆角、阴影与设计 token 统一

### 性能与可访问性

- [ ] 首屏与列表：必要时的虚拟滚动或分页，减少 DOM
- [ ] 关键操作：防重复提交、乐观更新（可选）
- [ ] 键盘与焦点：弹窗内 Tab 顺序、Esc 关闭
- [ ] 色彩对比与焦点环：满足基本 a11y
