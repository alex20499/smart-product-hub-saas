# 产品管理优化：仅列表、无主图、链接优先

> 新开聊天时扫描本文档即可续上进度。

## 节点记录

- **产品录入端完全跑通**（当前节点）：产品管理仅列表、无主图、链接优先；仪表盘与详情统一为占位+「打开官网」；DB 主图已一键清空。新增/编辑/保存流程稳定可用。

## 决策摘要

- **放弃 Grid 模式**：产品管理只保留**列表（List）**，移除网格/卡片视图切换。
- **去掉主图字段**：详情页、编辑弹窗、新增表单中**不再展示或编辑主图**；需要看图时通过**产品链接**跳转官网（乐天/亚马逊/雅虎 Shopping）。
- **链接优先**：列表与详情中链接列/按钮突出，可点击新开 tab。

## 已实施项（对照检查）

- [x] 产品管理：移除 grid，仅保留 list 视图
- [x] 产品管理：列表表头/行中链接列明显、可点击「打开官网」
- [x] 详情区：移除主图展示；链接置顶、按钮「在官网查看」
- [x] 编辑弹窗：移除主图上传/展示控件
- [x] 新增产品：移除主图字段
- [x] 仪表盘等：产品展示弱化主图、强调链接（若有卡片则改为占位或文字+链接）

## 技术备注

- 数据库与 API 保留 `main_image` 字段，不删；前端不再依赖、不展示、不编辑。
- 保存时主图可传空或原值，避免报错。
- **清空库里已有主图**：运行 `node scripts/clear-main-images.js`（需配置 `.env` 的 `SUPABASE_URL`、`SUPABASE_SERVICE_ROLE_KEY`），会一次性将全部产品的 `main_image` 置空。
